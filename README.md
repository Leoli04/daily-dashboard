# 每日资讯看板

把 **AI 动态 / 财经市场 / 实时热搜** 汇总到一个页面。

- **一个 HTML 文件** —— 零 CDN、零后端、零在线字体，双击即开；断网回落到内嵌快照。
- **打开即刷新** —— 联网时由浏览器在打开那一刻直连数据源拉取当天数据，不需要服务器。
- **无凭证** —— 全部数据源公开且免 API Key，仓库里没有任何密钥。

在线站点：<https://leoli04.github.io/daily-dashboard/>

## 页面结构

| 一级页签 | 子页签 | 内容 |
|---|---|---|
| **AI 动态** | 当日 · 近 7 日 | 官方日报（当日）与 7 天条目流（分类筛选 + 折叠正文） |
| **财经市场** | 今日要闻 · 市场情绪 · 风险雷达 · 人气榜 · 日榜 | 实时快讯与指数行情、涨跌停与龙虎榜、拥挤度打分、人气榜 |
| **实时热搜** | — | 全网热搜榜 |

顶部并置两个时间：**数据日期**（内容属于哪一天，逐版块判定）与**更新于**（本次拉取时刻）。
盘面类版块取的是**报告交易日**的快照，所以页面上同时出现两个日期是如实反映，不是 bug。

## 目录结构

```
├─ src/                  页面源码（构建输入）
│  ├─ shell.html         DOM 骨架与页签
│  ├─ styles.css         样式
│  ├─ lib.js             数据层（UMD 双端同构：浏览器与 Node 共用同一份）
│  ├─ radar.js           风险雷达打分
│  └─ app.js             渲染与调度
├─ tools/
│  ├─ fetch-sources.js   抓全部数据源 → 归一化 → data/<date>.json（幂等）
│  ├─ build.js           拼装单文件 HTML，附 37 项构建期自检
│  ├─ snapshot-gate.js   快照健康闸门（供 CI 使用）
│  ├─ push-to-github.cmd 一键推送到 GitHub（含代理设置）
│  └─ verify/            浏览器验证：check.js / probe.js / crop.js / layout.js
├─ data/                 每日快照（.gitignore 排除，不入库）
└─ .github/workflows/    定时抓取 → 构建 → 发布 Pages
```

## 本地构建

需要 Node 18+，**无第三方依赖**：

```bash
node tools/fetch-sources.js     # 抓当天数据（幂等：当天快照已存在则跳过；--force 强制重抓）
node tools/build.js             # 拼装单文件产物，并跑 37 项自检
```

`build.js --out=<path>` 可指定输出路径。**自检不通过时进程以 1 退出** —— CI 靠这个判成败。

浏览器端回归（需本机 Chrome，零依赖 CDP）：

```bash
node tools/verify/check.js      # 五场景：冷启动 / 同日缓存 / 断网降级 / 强制刷新 / 页签切换
node tools/verify/layout.js     # 多断点顶栏几何
node tools/verify/probe.js      # 通用探针：任意宽度与页签下执行表达式（--tab= / --sub= / --offline）
```

## 数据来源

全部公开、免鉴权，按用途分五类：

| 类别 | 来源 |
|---|---|
| AI 资讯 | AI HOT（官方日报接口 + 条目流接口） |
| 指数行情 | 腾讯行情（A股 / 港股 共 8 个指数）、东方财富 |
| 财经快讯 | 华尔街见闻（A股 / 港股 / 美股 / 全球 四个频道） |
| 市场情绪 | 东方财富（涨跌停池、龙虎榜、融资融券、概念与行业板块）、同花顺（人气榜） |
| 全网热搜 | 百度热搜 |

页面直连的能力取决于各源自身的 CORS 策略。**百度热搜没有 CORS 头，浏览器拿不到**，只有 Node 抓得到 —— 因此它走「定时快照 + 内嵌」这条路（见下节）。

## 自动化

`.github/workflows/refresh.yml`：抓取 → 构建 → 发布到 GitHub Pages。**三种触发方式**：

| 触发 | 时机 |
|---|---|
| `push` | 推送到 `main` 即部署一次（首次上线不用等定时任务；保活提交除外，见 `paths-ignore`） |
| `schedule` | 北京时间每天两次 08:30 / 20:30；另有每月 1 号 12:00 只跑保活 |
| `workflow_dispatch` | 手动：repo → Actions → 左侧 `refresh-dashboard` → **Run workflow** |

它**不决定页面打开时的实时性**（那由浏览器直连决定），刷新的只是：

1. **内置快照** —— 断网或接口全挂时的兜底；
2. **百度热搜** —— 唯一浏览器拿不到的源。

两个必要设计：

- **快照闸门**：抓取脚本对「个别源失败」是非致命的（失败项记账后仍以 0 退出），所以 CI 不能只看退出码。`snapshot-gate.js` 校验快照是否完整（版块齐全、关键版块有数据、无失败项、日期不超前）；不健康则本 job 失败 → deploy 不执行 → Pages 继续供应上一版好数据（宁旧勿残）。抓取最多重试 3 次。
- **每月保活提交**：公开仓库的 scheduled workflow 连续 60 天无提交活动会被自动停用，而产物走 artifact 发布、不回写仓库，所以每月 1 号补一次保活提交。

## 已知限制

- **「实时热搜」在线上永远是快照数据**（百度热搜无 CORS 头），最旧可能到 12 小时。其余 19 个源不受影响，打开即刷。
- 快讯是第三方通稿流，**不标注原始媒体名**；每个频道只取最新一页，且只展示最新一天。
- 盘面类版块（市场情绪 / 风险雷达）是**报告交易日**的快照，非交易日打开会看到上一交易日的日期。
- 浏览器实时拉到的数据缓存在 `localStorage` 供当天复用，不跨天复用；清掉缓存或断网即回落快照。
- 上游均为非官方公开接口，改版可能导致个别版块降级显示（页面会如实标注来源与日期）。
